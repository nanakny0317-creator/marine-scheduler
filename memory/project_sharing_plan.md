2026-11-13 にユーザーと決めた方針。

## 方針
- 将来は他のPCでも閲覧・印刷できるようにしたい。ただし今は進めない。印刷まわりの機能が固まってから、複数PCで使い始める前に取りかかる
- 個人情報を扱うので、素人判断でクラウド（Supabase など）に上げることはしない
- データは今のまま SQLite（dev.db）。読み書きは electron/db/ にまとまっているので、後で共有の仕組みに切り替えるときも主にそこを差し替える
- PostgreSQL の古い設定（pg パッケージ・.devcontainer の postgres）は 2026-11-13 に削除済み。アプリ本体は元から使っていなかった

## 最初にやる形：閲覧用アプリ
- 今のアプリをもとに「閲覧・印刷はできるが、追加・変更・削除はできない」版を作り、他のPCにはそれだけを入れる
- ボタンを隠すだけでなく、Electron のメインプロセス側で書き込みの IPC を止める（誤操作でもデータが変わらないように）
- データの渡し方：事務所内の共有フォルダ（親機のデータフォルダを読み取り専用で共有）がおすすめ。閲覧用アプリに「最新を読み込む」ボタンを付ける。USB コピーでも可
- 作るときに親機側の保存方法も安全にする：今は db.export() をそのまま writeFileSync しているので、一時ファイルに書いてから置き換える形にする（読み込み中に途中のデータを読まないように）
- 閲覧用PCにも Windows のログインパスワードを設定してもらう。可能なら BitLocker も

## それまでの注意
- dev.db を OneDrive などで共有して2台で同時に編集しない。今の仕組みはファイル全体を上書き保存するので、片方の入力が消える。別PCでは閲覧や画面確認用のコピーとしてだけ使う

**Why:** 個人情報を扱うのでクラウドを避けたい・口頭の「閲覧だけ」では不安、というユーザーの意向。
**How to apply:** 印刷まわり（[[project_ocr_print_next]]）が一段落したら、この方針で閲覧用アプリから提案する。
